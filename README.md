This program is used to perform nonergodic ground motion prediction for shallow crustal earthquakes in Japan using the model
developed by Hou et al. (2025). The nonergodic GMM is developed using the method proposed by Lavrentiadis, Abrahamson et al. 
(2023, published in BEE), in which the Gaussian process regression is the kernel. 


Reference:
[1] Hou R, Ji K, Liu M, et al. (2025) Nonergodic ground motion modeling for the subduction zone in Japan accounting for spatial 
    variation in source, path, and site effects. Earth Science (in Chinese)
[2] Hou R, Zhao J. 2024. Ground motion prediction equations for the horizontal component from shallow crustal 
    and upper mantle earthquakes in Japan using site period as site parameter. Bulletin of Earthquake Engineering, 22: 763-794.
